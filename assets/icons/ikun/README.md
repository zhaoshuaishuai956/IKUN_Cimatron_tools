# IKUN 梗图插件图标库

这里存放 32 张待用的 IKUN 梗图头像，均已处理为插件可直接使用的图标。

- `ico/`：16/32/48/64/128/256 多尺寸 ICO（推荐直接使用）
- `png64/`：64×64 PNG
- `png512/`：512×512 PNG（需要重绘/裁切时用）
- `preview.png`：待用图标总览（不含已使用的 #59 / #64）
- `sources.txt`：每张图的原始下载地址

**#59 已被「NC重命名」使用，#64 已被「顶针顶面拉平」使用**，两者均已移出待用库。

顶针顶面拉平图标源文件：`plugins/ejector-pin-flatten/payload/common/EjectorPin_icon64.ico`。

## 后续插件用法

1. 从 `ico/` 选一个编号。
2. 复制到 `plugins/<插件目录>/payload/common/<插件名>_icon64.ico`。
3. 在 `plugin.json` 的 `iconSource` 指向该文件。
4. 运行 `安装.cmd`；插件启动时会把它投放到 Cimatron 的 `DataDir\Images\Commands\<命令ID>_IKUNtools.ico`。
